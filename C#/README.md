# Exercícios da Página 77 - Capítulo 4 (Dividir para Conquistar)

## 📌 Exercício 4.1: Soma Recursiva
- **Lógica utilizada:** 
  1. **Caso-base:** Se a lista estiver vazia (`[]`), retornamos `0`.
  2. **Caso recursivo:** Pegamos o primeiro elemento e somamos com o resultado da função chamando o restante da lista (`lista.slice(1)` no JS ou `.Skip(1)` no C#).
- **Linguagens utilizadas:** JavaScript e C#.
